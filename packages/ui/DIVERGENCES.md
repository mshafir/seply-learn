# Divergences from prebuilt shadcn

The UI uses prebuilt shadcn (Base UI) components first. Everything custom is listed here: why it exists, what it's built from and which package owns it. Spec: [docs/spec/v1/07-design-system.md §7.1](../../docs/spec/v1/07-design-system.md). The inventory behind this list is in [the shadcn research](../../docs/wayfinder/mindmaps-v1/research/shadcn-base-ui.md).

All 8 are accepted. Entries marked *planned* are not built yet; the work package that builds one fills in its entry.

| # | Divergence | Why | Built from | Owner | Status |
|---|---|---|---|---|---|
| 1 | **Expedition canvas** | No shadcn component draws a pannable graph of Concepts and Relationships with dashed Proposals, streaming placeholders and read checks. | React Flow (`@xyflow/react`) with custom nodes made of Badge, Tooltip, HoverCard and ContextMenu; overlays of Button, ButtonGroup and Tooltip; `--xy-*` variables mapped to tokens; `colorMode={resolvedTheme}`. | `@seply/views` | planned |
| 2 | **View renderers** (non-canvas: table bands, outline, anatomy, quadrant, rates, lineage, plus Map and Timeline) | Each View Type has its own layout; none is a stock component. | Table (+ TanStack Table), Skeleton, Badge, Collapsible/Accordion, Item; MapLibre for Map; vis-timeline for Timeline. The Comparison Table (WP-1.6) is a semantic `<table>` with the same structure as shadcn's Table, styled with `--seply-*` variables that point at the tokens, because `@seply/views` may not import `@seply/ui` (dependency rule); swap in the shadcn Table once the app can inject it. The Outline, Quadrant and Rates (WP-2.2) follow the same rule: the Outline is a `role="tree"` list of plain buttons (a Collapsible per line in shadcn terms), the Quadrant a CSS grid of card buttons, and Rates a grid of rows each holding an inline SVG log axis; all styled with `--seply-*` variables. | `@seply/views` | Comparison Table built (WP-1.6); Outline, Quadrant, Rates built (WP-2.2); the rest planned |
| 2 | **View renderers** (non-canvas: table bands, outline, anatomy, quadrant, rates, lineage, plus Map and Timeline) | Each View Type has its own layout; none is a stock component. | Table (+ TanStack Table), Skeleton, Badge, Collapsible/Accordion, Item; MapLibre for Map (pins are HTML Markers: a Kind-coloured dot with a label chip, and the "Detailed map unavailable" note is a rounded chip, both on `--seply-map-*` variables over tokens; the coarse world's colours are tokens resolved to rgb for MapLibre); vis-timeline for Timeline. The Comparison Table (WP-1.6) is a semantic `<table>` with the same structure as shadcn's Table, styled with `--seply-*` variables that point at the tokens, because `@seply/views` may not import `@seply/ui` (dependency rule); swap in the shadcn Table once the app can inject it. | 3 | **Thumbnails** | A miniature per View Type for Library cards and the Views rail. | `src/components/view-type-thumbnail.tsx` (`ViewTypeThumbnail`): a fixed 220×110 SVG per View Type, ported from the design artboard (`Thumb.dc.html`), every colour a token class (`fill-kind-*`, `stroke-input`, `fill-card`, `fill-muted`, `fill-suggested/20` …) so it follows the theme; an empty dashed frame when there are no Views. Moved from `@seply/views` to `@seply/ui`: it draws no Expedition data, and the Library (not a View) is its first user. | `@seply/ui` | built (WP-2.7) |

| 5 | **Step indicator** (Sources → Choose Views → Open) | shadcn has no stepper; one component serves the horizontal wizard and the vertical build stage list. | Separator, Badge and Spinner, laid out with flex. | `@seply/ui` | planned |
| 6 | **File drop zone** | shadcn has no drop target. | A native drag-and-drop area styled with tokens (dashed `--border`), wrapping Button and Input (`type=file`). | `@seply/ui` | planned |
| 7 | **Attribute list** | A key/value `<dl>`; minor. | `src/components/attribute-list.tsx`: a semantic `<dl>` in a two-column grid on `bg-muted/50`, labels in `text-muted-foreground`. | 8 | **Badge variants** (extension) | Build status (`success`, `progress`, `queued`) and provenance (`source`, `background`) need colours shadcn's Badge doesn't have, plus a pulsing status dot. | New `cva` variants on the shadcn Badge, using `--success`, `--suggested`, `--suggested-text` and `--muted`. Provenance: `source` is `bg-suggested/15 text-suggested-text`, `background` is `bg-muted text-muted-foreground`. | `@seply/ui` | provenance built (WP-1.7); status planned |
