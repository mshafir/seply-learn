# WP-5.5: Connect an agent — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in reader opens `/connect`, picks their agent, copies its install commands, sees it connect, and copies a first prompt.

**Architecture:** The page is one screen in `apps/web`. Everything that decides *what text to show* (commands per agent, hosted or self-hosted, first prompts, which agent is new) is a pure module with unit tests; the screen only lays it out. The server gains one public route, `GET /api/instance`. The plugin's server address becomes a `userConfig` option with the hosted address as its default.

**Tech stack:** React 19, wouter, shadcn/Base UI components from `@seply/ui`, Hono, Vitest, Playwright.

**Spec:** `docs/spec/v1/06-mcp.md` §6.4, `docs/spec/v1/09-desktop.md` §9.2 (`/api/instance`).

**Out of this plan:** the desktop menu item and first-run landing (WP-7.3); everything else in M7.

## Global constraints

- Copy uses the glossary: Expedition, Concept, View, "suggestions". Plain sentences.
- Prebuilt `@seply/ui` components only; no new divergence; colours from tokens.
- `apps/web` and `packages/server` sources are not Prettier-formatted wholesale: format only new files, match the file being edited otherwise.
- The server address shown is always `window.location.origin + "/mcp"`.
- The hosted origin is exactly `https://learn.seply.app`.
- Agents, in order: Claude Code, Claude apps, Codex, Cursor, Other.
- Verified commands (2026-10-12):
  - `claude plugin marketplace add mshafir/seply-learn`, `claude plugin install seply-learn@seply`
  - `claude mcp add --transport http seply-learn <origin>/mcp`
  - `codex mcp add seply-learn --url <origin>/mcp`, `codex mcp login seply-learn`
  - `cursor://anysphere.cursor-deeplink/mcp/install?name=seply-learn&config=<base64 of {"url":"<origin>/mcp"}>`

## Review focus

1. **An Expedition title with quotes or a newline** in the first prompt: the prompt stays one line and readable (quotes swapped for typographic ones, whitespace collapsed). Test in Task 2.
2. **An origin with a port or `http`** (a home self-host): every command carries it unchanged, and the Cursor link's base64 decodes to it. Test in Task 2.
3. **An agent that was already connected** before the page opened: step 3 does not tick itself for it. Test in Task 2.
4. **`/api/instance` or `/api/agents` failing** (an older server, offline): the page still shows self-hosted-safe commands (`mcp add`) and the step can be passed by hand. Test in Task 3 (unit, default) and Task 5 (e2e route abort).
5. **`?e=` naming an Expedition the reader can't see:** the page falls back to the create prompts, no error. Test in Task 5.

### Task 2: the steps module

**Produces** (`apps/web/src/connect/steps.ts`):

```ts
export type AgentId = "claude-code" | "claude-apps" | "codex" | "cursor" | "other"
export const AGENTS: { id: AgentId; label: string }[]
export type Instance = { hosted: boolean }
export type InstallItem =
  | { kind: "command"; label: string; value: string }
  | { kind: "text"; text: string }
  | { kind: "link"; label: string; href: string }
  | { kind: "token" }            // the create-a-token form, Other only
export function installSteps(agent: AgentId, origin: string, instance: Instance): InstallItem[]
export function signInSteps(agent: AgentId): string[]
export function firstPrompts(expedition: { title: string } | null): { label: string; prompt: string; then: string }[]
export function newAgent(before: AgentsOverview, now: AgentsOverview): string | null
export function cursorInstallLink(origin: string): string
```

- [ ] Tests first, covering: each agent hosted and self-hosted (Claude Code hosted = two plugin commands; self-hosted = a text step naming the address to enter, the two plugin commands, and the `mcp add` alternative); Claude apps self-hosted adds the "reachable over https" note; origin with port and `http` carried unchanged; the Cursor link decodes to `{"url": "<origin>/mcp"}`; prompts with and without an Expedition; a title with `"` and a newline; `newAgent` returns a grant's name when its `clientId` is new, a token's name when its `lastUsedAt` went from null to set, and null when nothing changed or the agent was there before.
