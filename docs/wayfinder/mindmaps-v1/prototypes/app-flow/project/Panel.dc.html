Grouped-Query Attention (GQA)
#technique
Query heads in groups, one K/V head per group: most of MQA's savings, little loss
Maturitystandard Buysefficiency AttacksKV-cache size
GQA is the compromise between multi-head attention and MQA. Query heads are split into groups, and each group shares one key/value head. With 32 query heads in 8 groups of 4, you store 8 K/V sets instead of 32, a 4× smaller KV-cache. It is now the near-universal default: Llama 4, Qwen3 and SmolLM3 all use it.

Grouped-Query Attention (GQA)
How it worksThe numbersTrade-offsFrom the chat

GQA sits between two extremes. Multi-head attention gives every query head its own keys and values; MQA makes every head share one. GQA picks a middle number of K/V heads and assigns each to a group of query heads.
