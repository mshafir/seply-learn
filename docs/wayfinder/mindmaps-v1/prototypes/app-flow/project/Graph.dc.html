Multi-head Latent Attention (MLA)
#technique#attention
Cache a compressed 512-dim latent instead of full K/V (~32× smaller)
MLA is DeepSeek's answer to the KV-cache problem, introduced with DeepSeek-V2 in 2024. Instead of sharing K/V heads like GQA, it compresses each token's keys and values into one small latent vector, caches only that, and reconstructs per-head K and V when needed, ~32× smaller. Because RoPE doesn't survive compression, a separate 64-dim positional slice rides alongside.
